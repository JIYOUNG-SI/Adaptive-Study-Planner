
# 프로젝트 소개

MetaStudy는 메타인지(Metacognition)를 기반으로 한 적응형 학습 플래너입니다.

기존의 스터디 플래너가 단순히 일정과 할 일을 관리하는 데 집중했다면, MetaStudy는 사용자가 자신의 학습 상태를 스스로 점검하고 부족한 부분을 파악할 수 있도록 돕는 것을 목표로 합니다.

학습 시간, 복습 주기, 자기평가 데이터를 활용하여 단순한 일정 관리가 아닌 효율적인 학습 의사결정을 지원하는 웹 애플리케이션입니다.

---

# 개발 배경

공부를 하다 보면 다른 사람들의 공부법을 참고하는 경우가 많지만, 정작 자신이 무엇을 알고 있고 무엇을 모르는지 명확하게 파악하지 못하는 경우가 많았습니다.

또한 시험 기간이 다가오면 이미 충분히 이해한 내용과 부족한 내용을 구분하지 못해 비효율적으로 학습하는 경우도 자주 경험했습니다.

이 과정에서 메타인지(Metacognition)가 학습 효율 향상에 중요한 역할을 한다는 연구와 기사들을 접하게 되었고, 자신의 이해도를 스스로 점검하며 학습하는 것이 단순 반복 학습보다 효과적이라는 점에 관심을 가지게 되었습니다.

그래서 사용자가 자신의 학습 상태를 객관적으로 확인하고, 필요한 복습을 적절한 시점에 수행할 수 있도록 돕는 메타인지 기반 학습 플래너를 개발하게 되었습니다.

---

# 문제 정의

## 기존 스터디 플래너의 한계

* 종이 플래너는 항상 휴대하기 어렵다.
* 어제 완료하지 못한 일정이 자동으로 반영되지 않는다.
* 직접 작성하고 관리해야 하므로 번거롭다.
* 공부 시간을 기록하더라도 학습량이 직관적으로 보이지 않는다.
* 학습 데이터가 누적되지 않아 장기적인 분석이 어렵다.

## 메타인지 측면의 문제

많은 학습자들은 자신이 알고 있다고 생각하는 내용과 실제로 이해하고 있는 내용 사이에 차이가 존재한다.

이러한 착각은 시험 직전에 드러나는 경우가 많으며, 이미 이해한 내용에 시간을 과도하게 사용하거나 정말 부족한 부분을 놓치는 문제를 발생시킨다.

따라서 학습 과정에서 자신의 이해도를 지속적으로 점검하고 객관적으로 확인할 수 있는 도구가 필요하다.

# 주요 기능

## 학습 일정 관리

* 과목별 학습 일정 생성
* 우선순위 설정
* D-Day 관리
* 일정 완료 상태 관리

## 공부 시간 측정

* 내장 타이머 제공
* 실제 학습 시간 자동 기록
* 누적 공부 시간 계산

## 메타인지 기반 자기평가

* 학습 완료 후 이해도 평가
* Confidence Score 기록
* 자기 이해 수준 점검

## 자동 복습 시스템

* 자기평가 결과 기반 복습 일정 생성
* 복습 우선순위 관리
* 학습 내용 재노출

## 학습 분석

* 공부 시간 통계
* 과목별 학습 현황
* 학습 패턴 시각화
* Learning Analytics 제공

## 학습 습관 형성

* 오늘 공부 시간 표시
* 연속 공부일(Streak) 관리
* 동기부여 메시지 제공

# 개발 과정 및 시행착오

초기 버전에서는 멘토 기반 동기부여 기능을 기획하였습니다.

하지만 개발 과정에서 단순 동기부여 메시지는 실제 학습 성과와 직접적인 관련성이 낮다는 점을 확인하였고, 사용자가 실질적으로 도움을 받을 수 있는 방향에 대해 고민하게 되었습니다.

그 결과 프로젝트의 핵심 기능을 메타인지(Self Assessment) 기반 학습 지원 시스템으로 전환하였습니다.

또한 개발 초기에는 GitHub 기반 버전 관리 없이 코드를 수정한 후 바로 Netlify에 배포하는 방식으로 개발하였습니다.

이 과정에서 코드 관리가 어려워지고 기능 수정 시 기존 기능에 영향을 주는 문제가 발생하였습니다.

이후 GitHub를 통한 버전 관리와 Antigravity를 활용한 개발 프로세스를 도입하여 기능별 구현과 테스트를 체계적으로 진행할 수 있었고, 개발 속도와 유지보수성을 개선할 수 있었습니다.
